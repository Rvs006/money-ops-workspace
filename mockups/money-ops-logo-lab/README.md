# Money Ops icon studio

Run `npm install` and `npm run dev -- --port 5178`. Open http://127.0.0.1:5178.

Choose Standard, Compact or Open aperture, then drag the DialKit controls. SVG, transparent 1024px PNG and JSON downloads use the current values. Versions retain alternatives in this browser. Copy parameters copies DialKit's configuration.

`npm run export-assets` regenerates the default SVG, transparent PNG, white app icon, favicon and configuration in `assets/`. `npm run build` builds the standalone studio.

The native app uses the default mark in `../finance-native/Logo.js`. Studio changes do not automatically update that component. Apply your chosen settings and re-export assets when selecting a replacement.

The original construction uses a solid folded document with a transparent M aperture. It uses the existing Money Ops palette. QuiverAI was unavailable; this artwork was authored locally.
